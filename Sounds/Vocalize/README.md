## Instructions for adding new Vocalizations

1. Create a new folder in this directory: e.g. ./MyVoice
2. Add the following REQUIRED ogg files to the new directory:
	'0.ogg'
	'1.ogg'
	'2.ogg'
	'3.ogg'
	'4.ogg'
	'5.ogg'
	'6.ogg'

	'18.ogg'
	'19.ogg'
	'20.ogg'
	'30.ogg'
	'40.ogg'
	'50.ogg'
	'60.ogg'
	'70.ogg'
	'80.ogg'
	'90.ogg'
	'100percent1.ogg'
	'point.ogg'
3. Add the following OPTIONAL ogg files for quads (one will be picked randomly)
    '100percent2.ogg'
	'100percent3.ogg'
	etc.
4. Enable Vocalizations in the song "Advanced options" menu

Some voice packs can be found here https://github.com/concubidated/simply-love-openitg/tree/master/Vocalize
